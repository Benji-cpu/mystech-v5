## Stuck readings

The JSON does not yet include `stuckReadingRows` (the route hasn't been updated to emit individual rows). 14 readings have `interpretation IS NULL` after more than 5 minutes, windowed to the last 7 days — roughly 2 per day on average.

At 2/day this is a consistent low-level bleed rather than a single outage spike. Most likely causes, in order:
- **Abandoned tabs** — user opened the reading flow, never clicked through to interpretation. The stream starts, nobody is listening, interpretation never writes to DB.
- **Gemini timeout / silent failure** — `streamText()` opens and closes without writing `interpretation`. Would show as zero-length chunks in Vercel Function logs for `/api/ai/reading`.
- **DB write failure after stream** — stream completes but the final `UPDATE readings SET interpretation = ...` fails silently.

Two or more on the same calendar day would indicate an outage window; with only counts we can't tell yet. Add `stuckReadingRows` to the cron route to triage future digests by spread type and timestamp cluster.
